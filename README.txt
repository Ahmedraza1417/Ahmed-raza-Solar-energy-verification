Ahmed Raza Solar Energy — FREE QR Verification

Files:
- index.html
- verify.html

Deployment:
Upload these files to a free HTTPS static host such as GitHub Pages or Cloudflare Pages.
After deployment, copy the public site URL into the solar app:
Settings → Online Verification → Public Verification Base URL

Example:
https://YOUR-SITE/verify.html

Do not put customer payment information or app login credentials into public QR data.
